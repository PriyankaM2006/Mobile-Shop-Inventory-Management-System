📋 URL Parameter Format

The payment page accepts these URL parameters:

/online_payment?name=John&email=john@email.com&phone=9876543210&amount=5000&product=Smartphone&address=123%20Street
Parameter Purpose Example
name Customer name John%20Doe
email Customer email john@email.com
phone Phone number 9876543210
amount Payment amount (in paise) 25000
product Product name Smartphone
address Delivery address 123%20Main%20Street

How it works:

  1. Select a product from the dropdown
  2. Amount automatically updates with product price
  3. QR code regenerates with new amount
  4. Scan QR or copy payment link to pay

🎯 QR Code Features

  • Dynamically generated based on current amount
  • Updates when product selection changes
  • Includes UPI ID: yourname@upi
  • Includes merchant name: Your Shop Name
  • Scannable by any UPI app (Google Pay, PhonePe, etc.)
  • Copy Payment Link button for sharing

✅ Payment Flow

  1. User clicks "Pay Now" from purchase history
  2. Payment page loads with auto-filled customer details
  3. Amount auto-fills from purchase amount
  4. QR code displays with correct amount embedded
  5. User can:
    • Scan QR with any UPI app to pay
    • Select different product from dropdown (updates amount and QR)
    • Copy payment link to share or pay manually
  6. Payment confirmation redirects to success page
